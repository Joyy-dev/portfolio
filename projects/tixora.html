Tixora: Frictionless Live Event Passes

High-throughput event booking app with secure QR ticket validation, interactive seating charts, and Apple/Google Wallet integration.

Role

Lead Flutter Engineer

Tech Stack

Flutter, Dart, Stripe SDK, Cloud Functions

Key Tech

Encrypted QR Codes, Offline Passbook

Project Overview

Tixora provides event attendees with instant booking confirmation, seat previews, and dynamic rolling barcodes that prevent ticket counterfeiting and screenshot transfers.

Key Features

  • Custom Interactive Seating Map: Custom Canvas-rendered seat selection engine capable of rendering 5,000+ interactive seats at 60 FPS without frame drops.
  • Stripe Payment Sheet: One-tap checkout with Apple Pay and Google Pay integration.
  • Offline Pass Vault: Cryptographically signed ticket pass generated locally and cached for admission gate scanners even without cellular coverage.
