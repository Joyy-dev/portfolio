On-Demand Service Platform

LocalFixers: Connecting Homeowners with Trusted Techs

An end-to-end mobile service marketplace built with Flutter, Firebase Auth, Cloud Firestore, and real-time geolocation matching.

Role

Mobile App Developer / UI

Tech Stack

Flutter, Dart, Firebase, Google Maps

Platform

iOS & Android

Project Overview

Finding reputable home repair professionals is often stressful, opaque, and slow. LocalFixers solves this by streamlining service requests, verified worker matching, instant in-app messaging, and clear pricing upfront.

Key Features & Architecture

  • Geo-radius Discovery: Utilizes geofire queries to find nearby plumbers, electricians, and carpenters in sub-second response times.
  • Real-Time Booking State: Seamless status lifecycle (Requested, Accepted, En Route, In Progress, Completed) synchronized via Firestore streams.
  • Review & Verification System: Transparent identity verification and post-job review mechanism to foster user trust.

Technical Highlights

Architected using feature-first directory layout and BLoC pattern for deterministic state handling across complex booking flows and offline network reconnects.
