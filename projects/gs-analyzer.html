GS Analyzer: Spreadsheet Intelligence Dashboard

A desktop and web analytics client that transforms raw Google Sheets spreadsheets into interactive statistical charts, cohort funnels, and alert notifications.

Role

Full-Stack Mobile & Desktop Dev

Tech Stack

Flutter Desktop/Web, Google Sheets v4 API

Key Features

OAuth2, Real-time Webhooks, Charting

Project Overview

Small businesses and creators rely heavily on Google Sheets for tracking leads, sales, and operations. GS Analyzer connects securely to authorized sheets via OAuth2 and instantly generates executive dashboards without complex formulas.

Key Features

  • Automated Schema Detection: Analyzes column headers, dates, currencies, and numeric series to automatically generate suitable charts (Bar, Sparkline, Pie, Trend).
  • Anomaly Detection Engine: Flags sudden changes in metrics compared against rolling 30-day moving averages.
  • Cross-Platform Consistency: Built once in Flutter and deployed seamlessly across macOS, Windows, and Web.
